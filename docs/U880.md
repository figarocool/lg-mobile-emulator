# U880 V10b: funzionamento e limiti

[English](U880.en.md) · [Installazione](INSTALLAZIONE.md)

Il CODE originale viene riconosciuto tramite hash. Se cifrato, viene decifrato
con la chiave locale fornita dall'utente; se gia in chiaro, non serve la chiave.
In entrambi i casi l'AMSS risultante deve avere l'hash V10b atteso.

L'installatore avvia le routine originali per creare un filesystem simulato,
importa e verifica MODULE/MEDIA e inizializza una preferenza del database UI.
Il firmware non viene patchato. Metadati di fabbrica, USIM e hardware circostante
sono sintetici: non rappresentano il contenuto di un telefono fisico.

L'avvio nella finestra riparte dal reset CPU sulla flash preparata; alla
chiusura salva uno snapshot separato. Sono stati osservati reset/ATR della
USIM, lettura di ICCID/IMSI, home originale e navigazione in Messaggi.
Il modello della USIM aggiorna la directory corrente dopo SELECT di un EF
tramite percorso assoluto; questa correzione evita il precedente errore nel
driver durante le letture successive.

Supporto parziale: GPIO, tempi/IRQ approssimati, mappa tasti sperimentale,
nessun modello radio U880 completo. Non sono verificate tutte le applicazioni,
le chiamate, la fotocamera o l'audio U880. Il supporto V10a resta diagnostico.
